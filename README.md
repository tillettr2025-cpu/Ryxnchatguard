# 🛡️ RyxnChatGuard

**RyxnChatGuard** is a Minecraft server chat moderation plugin designed to automatically detect and punish rule-breaking chat behavior.

Built for **Paper 1.21+**.

---

## ✨ Features

- 🚫 Bad word / hate speech filtering
- 💬 Chat spam detection
- 📢 Advertising detection
- 🌐 Server IP detection
- 🧩 Cheat/client mention detection
- 🔤 Detects common misspellings of cheat clients
- ⚠️ Self-harm encouragement detection
- ☠️ DDoS / Doxx / SWAT threat detection
- 💰 Account-selling detection
- 🔨 Automatic warnings
- 🔇 Automatic mutes
- 🔨 Automatic bans
- 🌐 IP bans
- 📊 Offence tracking
- 👮 Staff alerts
- 🔑 Staff bypass permission
- ⚙️ Fully configurable punishments
- 🔄 Configuration reload support
- 🚀 Lightweight and server-friendly

---

## 📋 Requirements

- **Minecraft:** 1.21+
- **Server:** Paper 1.21+
- **Java:** 21+

---
